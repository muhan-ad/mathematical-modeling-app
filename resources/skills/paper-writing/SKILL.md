# 论文写作与排版技能

基于 workspace/notes/ 的分析与求解结果，撰写 paper/ 下的 LaTeX 论文：

## 1. 结构
- paper/main.tex 为主文件；分章 tex 放 paper/sections/（英文命名，如 01-abstract.tex、05-model.tex）
- 每问一节，含：分析准备 → 模型建立 → 模型求解 → 结果；图、表、公式均须被正文引用

## 2. 内容来源与诚实性
- 所有数值、图表、结论必须取自 workspace 中真实运行/生成的产物，并标注来源文件路径
- 严禁编造数据或"文献值"；某处没做就说没做
- 用简体中文撰写，自然段落为主，模型核心用公式表达而非文字

## 3. 公式 / 图 / 表 / 引用
- 公式：equation 环境，变量逐一说明，编号推导完整
- 图：只放 ASCII 文件名 png（fig_qX_N.png）；图上不写中文标题，标题由 \caption 承担
- 表：给出带标题与列说明的表格，表格文字单行不换行
- 参考文献：正文 \cite 与文末列表一一对应，按实际内容生成
- 需要引用公式的地方用 \ref / \eqref 与 \label 关联

## 4. 校验
- 写完用 latex_compile 验证 paper/main.tex 能编译；有 Error 先修复再继续
- 自查：摘要、目录、各节齐全；公式/图表/文献引用无悬空

## 铁律
- 所有 .tex 文件名与图名一律英文（ASCII）；LaTeX 可编译优先于花哨排版
