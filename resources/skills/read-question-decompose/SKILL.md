# 读题拆解技能

拿到题目后按以下流程执行：

## 1. 通读与信息提取
- 用 file_read 读取 problem/statement.md（及 attachments/ 下附件）
- 提取：背景描述、已知条件、约束、需要求解的问题（问题1/2/3…）、数据文件清单

## 2. 问题分类
判断每问属于哪类：优化 / 预测 / 评价 / 统计推断 / 机理建模 / 综合情形，
并注明判断依据。

## 3. 建模路线规划
对每一问给出：
- 候选模型（至少 2 个，含优劣对比）
- 所需数据与数据来源（题目附件 or 可合理假设）
- 预期的输出形式（数值表 / 图 / 公式）

## 4. 输出
- 用 file_write 把拆解结果写入 workspace/notes/solution-roadmap.md（英文命名，符合项目约定）
- 向用户汇报路线并等待确认后再进入求解（除非权限为全自动）
