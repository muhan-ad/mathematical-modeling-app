# 校对与编译成稿技能

在论文写作完成后执行交稿前检查：

## 1. 内容一致性校对
- 摘要/结论里的每个数值与正文/求解结果一致（对照 workspace/outputs/ 与 data/ 的实际输出）
- 每问的方法、公式、图、表都与 workspace/notes/ 的方案和求解一致
- 参考文献：正文 \cite 与文末列表一一对应，无悬空引用

## 2. 逻辑与完整性
- 检查：题目要求的每个问题是否都有对应章节与结果
- 目录、章节编号、图表编号连续；无未完成的 TODO / 空章节
- 关键结论是否都由实际运行数据支撑（禁止编造）

## 3. 编译成稿
- 用 latex_compile 编译 paper/main.tex
- 编译 Error 清零；Warning 尽量修复（Overfull/Underfull box、未引用图表等）
- 产出最终 PDF，确认页数与内容正常

## 4. 交付
- 汇报编译结果与 PDF 路径，列出仍存在但已说明的局限
- 若非全自动，交用户预览确认后再收尾

## 铁律
- 交稿前 Error=0；任何"留待核对"项都要在交付说明里点明，不静默带过
