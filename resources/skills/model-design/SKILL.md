# 建模方案设计技能

读题拆解（workspace/notes/solution-roadmap.md）产出后，对每一问设计模型方案：

## 1. 问题定性与方法选型
按问题类型给候选方法（含英文缩写），并用对比表说明取舍依据：
| 主方法 | 备选方法 | 适用场景 | 关键库/算法 |
|--------|---------|---------|------------|
| 如线性回归 | Ridge/LASSO | 小样本、多重共线性 | sklearn.linear_model |

- 优化类：目标函数 + 决策变量 + 约束三要素完整写出；给出求解算法（线性规划/整数规划/启发式）
- 预测类：明确评价指标（MAE/RMSE/R²/MAPE）与训练验证划分
- 评价类：指标体系构建 + 权重方法（熵权/层次分析）+ 综合评价（TOPSIS/模糊）
- 统计推断 / 机理建模：写出核心方程与假设条件

## 2. 数学表达
把核心公式写成可放入 LaTeX 的形式（equation 环境），变量逐一说明，
推导过程可复现、不跳步。公式不许用文字带过。

## 3. 数据与实现前提
- 明确每个模型所需列名/数据来自 workspace/data/ 哪个文件
- 数据不足时可做合理假设，但必须向用户明示是假设

## 4. 输出
- 把方案写入 workspace/notes/model-design.md（含每问的方法对比表与公式）
- 向用户汇报并等待确认（除非权限为全自动）后再进入求解

## 铁律
- 方案必须能被现有数据或明确假设支持；严禁编造"获奖级"空泛套路
- 文件名一律英文（ASCII），图存 workspace/figures/
